TimelyDAgger

Minimal, readable Python for Bridge-PCA monitoring and feedback-guided threshold adaptation. Bring your own frozen VLA features and expert intervention interface.

View the code and README Research project page Paper

Bridge-PCA

Fit a principal subspace to bridge features from in-distribution demonstrations. Monitor the distance of each new bridge feature from that subspace. Set the initial help threshold from the maximum score of each separate ID calibration rollout.

score(z) = ‖(I − VVᵀ)(z − μ)‖₂   →   request help when score(z) > γ

Feedback-guided Threshold Adaptation

Completed expert interventions provide a timing cue. Initial corrective reversal encourages an earlier request; policy–expert agreement without reversal allows a later request. A single threshold is updated for subsequent episodes.

γi+1 = γi exp(−β yi),   yi ∈ {+1, 0, −1}

The repository uses β = 0.05 as an illustrative conservative default. Cue tolerances also need to be chosen for the target robot; they are not paper-validated constants.

Try the mathematical core

cd TimelyDAgger-Code
python -m pip install -r requirements.txt
python -m examples.minimal

Only NumPy is required. The repository does not distribute checkpoints, datasets, a robot driver, or experimental pipelines.
